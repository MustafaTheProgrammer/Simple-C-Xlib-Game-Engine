# Simple-C-Xlib-Game-Engine
A small game engine written in C and Xlib which would provide the things I'd need to make the kinds of games that I'd like to make.
I plan for this to include:
-Sprite rendering:
 -Using PNGs
 -Using 2d arrays to represent sprites
-Audio
-Key input
-Mouse input
-FPS handeling
-A way to set pixel colors by palatte rather specifically RGB/RGBA
